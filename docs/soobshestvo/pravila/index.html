Rules

Честная игра сохраняет Ranked понятным и соревновательным для всех.

  1. Не используйте запрещённые модификации.
  2. Не используйте автоматизацию.
  3. Не ищите нечестное преимущество.
  4. Не мешайте ходу матча.
  5. Соблюдайте решения организаторов.
  6. Перед турниром проверяйте актуальный список запрещённых модификаций.

Организаторы могут уточнять правила.
