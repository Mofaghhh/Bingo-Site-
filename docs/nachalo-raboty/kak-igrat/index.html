How to play

  1. Start the mod

    Откройте нужный режим.

  2. Get comfortable in practice

    В тренировке можно изучить механику без соревнования.

  3. Enter the Ranked Lobby

    Для Ranked используется лобби.

  4. Find an opponent

    Запустите Matchmaking. После поиска оба игрока попадают в один матч.

  5. Prepare for the match

    Оба игрока получают равные условия: seed, Bingo-карту, генерацию мира и стартовую точку.

  6. Press Ready

    Отсчёт начинается, когда Ready нажмут оба игрока. После отсчёта начинается матч.

  7. Complete objectives

    Выполняйте цели Bingo быстрее соперника.
