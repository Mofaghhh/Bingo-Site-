# How to play

{% stepper %}
{% step %}

### Start the mod

Open the mode you want.
{% endstep %}

{% step %}

### Get comfortable in practice

Practice mode lets you learn the mechanics without ranked competition.
{% endstep %}

{% step %}

### Enter the Ranked Lobby

Ranked play uses the [Lobby](/docs/igra/lobbi).
{% endstep %}

{% step %}

### Find an opponent

Start [Matchmaking](/docs/igra/matchmaking). Once a match is found, both players enter the same game.
{% endstep %}

{% step %}

### Prepare for the match

Both players receive equal conditions: the seed, the Bingo board, world generation and the starting point.
{% endstep %}

{% step %}

### Press Ready

The countdown starts when both players press Ready. The match begins after the countdown.
{% endstep %}

{% step %}

### Complete objectives

Finish the Bingo objectives faster than your opponent.
{% endstep %}
{% endstepper %}
