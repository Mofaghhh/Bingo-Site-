# Matches

{% stepper %}
{% step %}

### Enter the match

Both players enter the same match.
{% endstep %}

{% step %}

### Receive equal conditions

Both players receive the same seed, Bingo board and world generation. They spawn at the same starting point.
{% endstep %}

{% step %}

### Load the world

Each player waits for the world to finish loading.
{% endstep %}

{% step %}

### Confirm Ready

Both players press Ready. The countdown starts once both are ready.
{% endstep %}

{% step %}

### Start the match

The match begins after the countdown. Complete the Bingo objectives faster than your opponent.
{% endstep %}

{% step %}

### Get the result

The winner takes the match result.
{% endstep %}
{% endstepper %}
