# Lobby

The Lobby belongs to ranked play. It is not a practice mode.

In the Lobby, players wait for the match to start and finish their preparation.

### Ready

1. Both players must be in the same match.
2. Both players must load the world.
3. Each player presses Ready.
4. The match does not start until the second player is ready.
5. The countdown starts when both players are ready.
6. The match begins after the countdown.

{% hint style="warning" %}
A single Ready is not enough. Both players must be ready before the match can start.
{% endhint %}
