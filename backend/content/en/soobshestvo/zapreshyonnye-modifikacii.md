# Banned modifications

In competitive Bingo Ranked matches and tournaments, victory must rely on game knowledge, world routing, and manual dexterity. Any modification granting an unfair informational, navigational, or automation advantage is strictly forbidden.

## Banned modifications list

| Category | Modifications |
| --- | --- |
| Cheat clients | Wurst, Meteor, Inertia, Impact, Aristois, BleachHack |
| Minimaps and radars | Xaero's Minimap, JourneyMap, VoxelMap, Antique Atlas, and any minimaps with entity radar, cave mode, or waypoints |
| Lighting and gamma | FullBright, Gamma Utils, Brightness Slider, and any mods artificially increasing brightness in darkness |
| Ore detection | X-Ray, DiamondGen, Ore Highlighter |
| Automation | Any auto clicker, AutoAttack, Auto Mine, Auto Fish, Baritone, Librarian Trade Finder, SeedCracker, SeedMapper, Tweakeroo, Client Tweaks, ChestESP |
| Building and bounding boxes | Litematica Printer, FastBreak, Accurate Block Placement, Easy Place, MiniHUD, BoundingBoxOutlineReloaded, Slime Chunk Finder |
| Block and container overlays | Jade, WTHIT, HWYLA, The One Probe, Peek, Shulker Box Tooltip, Simple Shulker Preview |
| Auto slot refill | Autototem, Elytra Swap, InventoryTotem |
| Damage and HP display | Health Indicators, Neat, TslatEntityStatus, MobHealthBar, Damage Indicators |
| Camera | All Freecam versions, Camera Utils, Modify Camera Collision, Camera Tweaks, CMDCam, in-match ReplayMod, Flashback |
| Chunk animation | ChunkAnimator, Chunks Fade In |
| PvP | Marlow's Crystal Optimizer, Hero's Anchor Optimizer, BetterPvP, CleanCut |
| Fog and visibility | No Fog, Lava Clear, and similar liquid or fog transparency features |
| Movement | InvMove, Wall-Jump, Accessible Step |
| Inventory | Mouse Wheelie, Inventory Profiles Next, Client Sort, Sort It Out!, Lightweight Inventory Sorting, Mouse Tweaks, More Mouse Tweaks |
| Other utilities | BedrockMiner, Client Vein Miner, Trajectory Preview |

{% hint style="danger" %}
Any modifications that read the world seed, highlight structures, or reveal container contents without opening them will result in immediate disqualification and a ban.
{% endhint %}

## Allowed clients and mods (Whitelist)

Any modification that does not alter game mechanics or provide an informational edge is allowed.

### Clients
* Feather Client
* Lunar Client
* Badlion Client

### Performance and FPS optimization (Fabric / Quilt)
* **Sodium** and **Lithium**
* **FerriteCore**
* **Entity Culling**
* **ImmediatelyFast**
* **ModernFix**
* **Memory Leak Fix**
* **Krypton**

### UI and visual enhancement
* **Iris Shaders** (shaders allowed if they do not grant X-Ray or liquid/fog bypass)
* **Sodium Extra** and **Reese's Sodium Options**
* **Mod Menu**
* **AppleSkin** (saturation and exhaustion display)
* **Continuity** and **Indium** (connected textures support)
* **Presence Footsteps** (acoustic footsteps)

### Skins and cosmetics
* **Custom Skin Loader**
* **Capes** / **Wavey Capes**
* **3D Skin Layers**
