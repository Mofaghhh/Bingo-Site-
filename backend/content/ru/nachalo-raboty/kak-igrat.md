# Как играть

{% stepper %}
{% step %}

### Запустите Minecraft с модом

В главном меню игры выберите раздел **Bingo Ranked**.
{% endstep %}

{% step %}

### Опробуйте тренировку

Если вы играете впервые, начните с [тренировочного режима](/docs/nachalo-raboty/vy-novichok-sygraite-v-trenirovku). Здесь можно спокойно изучить цели бинго и интерфейс без давления таймера и соперника.
{% endstep %}

{% step %}

### Перейдите в Ranked-лобби

Готовы к настоящей битве? Откройте соревновательный раздел [лобби](/docs/igra/lobbi).
{% endstep %}

{% step %}

### Запустите поиск игры

Нажмите кнопку [Matchmaking](/docs/igra/matchmaking). Система быстро подберёт соперника со схожим рейтингом ELO.
{% endstep %}

{% step %}

### Загрузка и равные условия

Оба игрока подключаются к одной игре с абсолютно идентичными условиями: общий сид мира, одинаковая точка появления и одна и та же таблица заданий.
{% endstep %}

{% step %}

### Подтвердите готовность (Ready)

Когда мир прогрузится, нажмите кнопку **Ready**. Как только оба игрока подтвердят готовность, запустится обратный отсчёт до старта.
{% endstep %}

{% step %}

### Выполняйте цели быстрее соперника

Добывайте предметы, выполняйте достижения и исследуйте мир. Прогресс отображается на вашей карточке в реальном времени. Первый, кто закроет нужную комбинацию целей, побеждает в матче!
{% endstep %}
{% endstepper %}
