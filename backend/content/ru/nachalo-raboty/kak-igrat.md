# How to play

{% stepper %}
{% step %}

### Start the mod

Откройте нужный режим.
{% endstep %}

{% step %}

### Get comfortable in practice

В тренировке можно изучить механику без соревнования.
{% endstep %}

{% step %}

### Enter the Ranked Lobby

Для Ranked используется [лобби](/docs/igra/lobbi).
{% endstep %}

{% step %}

### Find an opponent

Запустите [Matchmaking](/docs/igra/matchmaking). После поиска оба игрока попадают в один матч.
{% endstep %}

{% step %}

### Prepare for the match

Оба игрока получают равные условия: seed, Bingo-карту, генерацию мира и стартовую точку.
{% endstep %}

{% step %}

### Press Ready

Отсчёт начинается, когда Ready нажмут оба игрока. После отсчёта начинается матч.
{% endstep %}

{% step %}

### Complete objectives

Выполняйте цели Bingo быстрее соперника.
{% endstep %}
{% endstepper %}
