# Leaving a match and surrender

Surrender означает сдачу. Второй игрок автоматически получает победу.

### Leaving and disconnecting

Выход из мира или полное отключение считается поражением после серверной проверки.

{% hint style="warning" %}
Не выходите из матча, чтобы избежать поражения. Отключение или выход может быть засчитан как поражение после проверки сервера.
{% endhint %}
