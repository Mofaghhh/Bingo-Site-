# Lobby

Лобби относится к Ranked. Это не тренировочный режим.

В лобби игроки ожидают начала матча и завершают подготовку.

### Ready

1. Оба игрока должны находиться в одном матче.
2. Оба игрока должны загрузить мир.
3. Каждый игрок нажимает Ready.
4. Пока второй игрок не готов, матч не начинается.
5. Когда готовы оба, начинается отсчёт.
6. После отсчёта начинается матч.

{% hint style="warning" %}
Одного Ready недостаточно. Для старта матча нужны оба игрока.
{% endhint %}
