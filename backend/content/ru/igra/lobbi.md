# Лобби

Лобби — это предстартовая комната рейтингового матча, где игроки подключаются и подтверждают готовность.

Здесь происходит синхронизация сида и генерация мира. Игра не начнётся, пока оба участника не подтвердят готовность.

### Система Ready

1. Оба игрока подключаются к одной игровой сессии.
2. Игра генерирует мир с одинаковым сидом и загружает чанки.
3. Каждый участник нажимает кнопку **Ready**.
4. Если один из игроков ещё не нажал Ready, игра будет терпеливо ждать.
5. Как только оба игрока подтвердили готовность, запускается таймер обратного отсчёта.
6. По завершении отсчёта спадают ограничения и начинается матч!

{% hint style="warning" %}
Матч начнётся только тогда, когда **оба** игрока нажмут Ready. Если кто-то вышел до старта, матч отменяется без потери очков ELO.
{% endhint %}
