# Matches

{% stepper %}
{% step %}

### Enter the match

Оба игрока попадают в один матч.
{% endstep %}

{% step %}

### Receive equal conditions

Оба игрока получают одинаковый seed, Bingo-карту и генерацию мира. Они появляются в одной стартовой точке.
{% endstep %}

{% step %}

### Load the world

Каждый игрок ждёт завершения загрузки мира.
{% endstep %}

{% step %}

### Confirm Ready

Оба игрока нажимают Ready. Отсчёт начинается, когда готовы оба.
{% endstep %}

{% step %}

### Start the match

После отсчёта начинается матч. Выполняйте цели Bingo быстрее соперника.
{% endstep %}

{% step %}

### Get the result

Победитель получает результат матча.
{% endstep %}
{% endstepper %}
