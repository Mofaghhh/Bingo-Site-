# Changelog

### Версия 1.3.0 — Minecraft 26.3 (26.10.2026)

**Безопасность и аккаунты**

- Закрыли вход в Bingo Ranked для пиратских версий игры
- Кнопка входа в главном меню для нелицензионных версий теперь заблокирована замком
- При наведении на замок выводится подсказка о необходимости лицензии
- Внедрили проверку подлинности через официальные серверы Mojang
- Зайти под чужим ником больше нельзя
- Полноценная поддержка входа через Prism Launcher и Modrinth App
- Вход теперь запоминается и не требует подтверждения при каждом запуске

**Кастомные лобби**

- Создание приватных комнат и подключение по коду лобби
- Кнопка «Скопировать» для кода лобби теперь загорается галочкой
- Скины, ранги и награды участников теперь видны прямо в комнате ожидания
- Исправили синхронизацию статуса готовности игроков перед стартом

**Матчмейкинг и матчи**

- Экран поиска соперников с подбором равных по силе игроков
- Экран очереди ожидания с возможностью быстрой отмены
- Обратный отсчёт 3-2-1 перед началом матча
- Автоматическое завершение матча и фиксация победы при сборе любой линии
- Экран победы и поражения с наглядным изменением рейтинга

**Профиль игрока**

- Интерактивная 3D-модель персонажа с анимациями и эмоциями
- Предпросмотр и настройка модельки в меню параметров
- Поддержка обоих типов скинов: классического и тонкого

**Медали и турниры**

- Система турнирных наград: золотые, серебряные и бронзовые медали
- Медали отображаются рядом с ником игрока в профиле, лобби и таблице лидеров
- Подсказки с названием турнира и датой при наведении на медаль

**График рейтинга и статистика**

- Цветные отметки на графике при переходе в новый ранг
- Всплывающие карточки при наведении: дата, соперник и результат матча
- Личная статистика: процент побед, победы, поражения, ничьи и рекордный рейтинг
- Просмотр истории прошлых матчей со сменой страниц

**Таблица лидеров и поиск**

- Таблица лидеров теперь разбита по страницам для удобного просмотра
- Быстрый поиск игроков по никнейму с подсказками при вводе

**Чат и эмодзи**

- Добавили собственное меню смайликов и наборы эмодзи для чата и лобби
- В личных сообщениях теперь пишется ник собеседника

**Внешние интеграции**

- Привязка социальных сетей в профиле: Telegram, YouTube, Twitch, TikTok, Reddit, Instagram
- Клик по иконке соцсети сразу открывает профиль игрока в браузере
- Отображение игры в Discord: текущий режим, счёт в матче и ранг в статусе профиля

**Стабильность**

- Повысили стабильность подключения при сбоях интернета
- Синхронизация закрытия целей соперника в реальном времени
- Оптимизировали работу игры в меню и во время матча

### Версия 1.1.0 — Minecraft 26.3 (22.09.2026)

**Совместимость**

- Мод перенесён на **Minecraft 26.3** (было 26.2).
- Требования: Fabric Loader **0.19.5+**, Fabric API **0.161.0+26.3**, Java **25+**.

**Автообновление**

- Пока доступен новый релиз, меню Bingo и вход в матч блокируются: играть нельзя, пока мод не обновится.
- Кнопка «Доступно обновление» теперь обновляет мод сама: открывает страницу на Modrinth и скачивает новый jar.
- После обновления файл мода заменяется автоматически, старый jar удаляется при выходе из игры — просто перезапустите игру.

**Новые цели**

- Контент 26.3: тополь (брёвна, доски, жёлтые листья), соломенная кровать, гриб-полка.
- Карты исследователя: карта сокровищ, карта океанского монумента, карта лесного особняка.

**Прочее**

- Новый логотип мода.
- Обновлено описание Fabric-мода под 26.3.
