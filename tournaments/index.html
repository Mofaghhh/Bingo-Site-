1v1 Speedrun Duel

Классическая соревновательная дуэль один на один. Гонка на скорость до первой собранной линии из 5 целей на бинго-карте. Лимит времени на матч — 20 минут. Победитель определяется по первой закрытой линии либо по наибольшему числу выполненных целей по истечении таймера.
